# Портфолио — Алижан Болат

Одностраничный сайт-портфолио на HTML и CSS без фреймворков и сборщиков. JavaScript используется только для лайтбокса (GLightbox, MIT), без него сайт полностью работает, а картинки открываются по прямой ссылке.

**Сайт:** https://portfolio-bay-theta-29.vercel.app/

## Что внутри

- Сайдбар с именем, навигацией и компактными контактами (на десктопе закреплён при прокрутке, на телефоне идёт сверху)
- Разделы: обо мне, образование и языки, технический стек, проекты с видео, 3D-модели, лидерство, хакатоны и сертификаты
- Адаптивная вёрстка (mobile first) на CSS Grid и Flexbox
- Просмотр скриншотов и сертификатов в лайтбоксе GLightbox: листание, свайп, приближение, подпись и ссылка на PDF (библиотека лежит локально в `vendor/`)
- Статус «Открыт к предложениям» с пульсирующей точкой и кнопки «Написать в Telegram» в шапке и подвале
- Кейсы проектов раскрываются кнопкой «Развернуть кейс» (`<details>`, без JavaScript)
- Печатная версия (`@media print`): iframe с YouTube скрыт, вместо него заглушка с кнопкой Play и адрес видео; галерея и сертификаты не печатаются
- Open Graph и Twitter-теги, превью-карточка `og.png` (1200×630)
- Шрифт IBM Plex подключён локально из папки `fonts/`, внешних запросов и трекеров нет
- Дизайн-токены (цвета, радиусы, тени) в начале `style.css`

## Структура

```
.
├── index.html
├── style.css
├── favicon.svg
├── og.png             # превью-карточка для Telegram и LinkedIn
├── Alizhan_Bolat_CV.pdf  # резюме для кнопки «Скачать резюме»
├── js/main.js         # запуск лайтбокса
├── vendor/            # GLightbox (css и js)
├── fonts/             # IBM Plex Sans и Mono (woff2)
├── images/            # скриншоты 3D-моделей (screen1–5.webp)
└── certificates/      # превью (.webp) и оригиналы (.pdf)
```

## Как менять контент

| Что изменить | Где |
|---|---|
| Тексты разделов | `index.html`, нужная `<section>` |
| Навыки в стеке | `index.html`, раздел `#skills`, элементы `<li><b>Название</b><span>Описание</span></li>` |
| Ссылки GitHub и LinkedIn | `index.html`, блок `.contacts__social` |
| Цвета, шрифты, отступы | `style.css`, раздел «1. Токены» |
| Новый сертификат | файлы `.webp` и `.pdf` в `certificates/`, затем новый `<li>` в списке `.certs` по образцу соседних |
| Видео | ID в `src` у `<iframe>` (`youtube.com/embed/ID`) |


## Если смените хостинг или домен

`og.png` переделывать не нужно: на картинке нет адреса сайта. Замените адрес в трёх местах в `<head>` файла `index.html`: `rel="canonical"`, `og:url` и `og:image` (адрес картинки должен быть полным, вместе с `https://`). Также обновите ссылку «Сайт» в начале этого файла. Если новый адрес лежит не в корне домена (например, `site.com/portfolio/`), относительные пути `./` продолжат работать, а в `og:image` нужен полный путь.
