# Портфолио — Алижан Болат

Одностраничный сайт-портфолио на HTML и CSS без фреймворков и сборщиков. JavaScript используется только для лайтбокса (GLightbox, MIT), без него сайт полностью работает, а картинки открываются по прямой ссылке.

**Сайт:** https://portfolio-bay-theta-29.vercel.app

## Языки

Сайт двуязычный: русская версия в `index.html`, английская в `en/index.html`. Переключатель RU / EN стоит в шапке и работает обычными ссылками, без JavaScript. У страниц прописаны `hreflang` и отдельные Open Graph-теги, поэтому поисковики и соцсети показывают нужный язык. Стили, скрипты, картинки и шрифты общие.

**Важно:** тексты хранятся в двух файлах. Любую правку в содержимом нужно вносить и в `index.html`, и в `en/index.html`.

## Что внутри

- Сайдбар с именем, навигацией и компактными контактами (на десктопе закреплён при прокрутке, на телефоне идёт сверху)
- Разделы: обо мне, образование и языки, технический стек, проекты с видео, 3D-модели, лидерство, хакатоны и сертификаты
- Адаптивная вёрстка (mobile first) на CSS Grid и Flexbox
- Просмотр скриншотов и сертификатов в лайтбоксе GLightbox: листание, свайп, приближение, подпись и ссылка на PDF (библиотека лежит локально в `vendor/`)
- Статус «Открыт к предложениям» с пульсирующей точкой и кнопки «Написать в Telegram» в шапке и подвале
- Кейсы проектов раскрываются кнопкой «Развернуть кейс» (`<details>`, без JavaScript)
- Печатная версия (`@media print`): iframe с YouTube скрыт, вместо него заглушка с кнопкой Play и адрес видео; галерея и сертификаты не печатаются
- Open Graph и Twitter-теги, превью-карточка `og.png` (1200×630)
- Шрифт IBM Plex подключён локально из папки `fonts/`, внешних запросов и трекеров нет
- Дизайн-токены (цвета, радиусы, тени) в начале `style.css`

```
├── images/            # скриншоты 3D-моделей (screen1–5.webp)

```

## Локальный запуск

Для проверки лучше запускать локальный сервер (при открытии файла двойным кликом видео YouTube могут не играть, а переключатель RU / EN не откроет английскую страницу, потому что ссылки ведут на папки):

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `alizhan-bolat.github.io`.
2. Загрузите файлы так, чтобы `index.html` лежал в корне репозитория.
3. **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`**.
4. Через 1–2 минуты сайт появится по адресу из начала этого файла.

Обновление: `git add . && git commit -m "Update" && git push`.

## Как менять контент

| Что изменить | Где |
|---|---|
| Тексты разделов | `index.html`, нужная `<section>` |
| Навыки в стеке | `index.html`, раздел `#skills`, элементы `<li><b>Название</b><span>Описание</span></li>` |
| Ссылки GitHub и LinkedIn | `index.html`, блок `.contacts__social` |
| Цвета, шрифты, отступы | `style.css`, раздел «1. Токены» |
| Новый сертификат | файлы `.webp` и `.pdf` в `certificates/`, затем новый `<li>` в списке `.certs` по образцу соседних |
| Видео | ID в `src` у `<iframe>` (`youtube.com/embed/ID`) |

## Если смените ник на GitHub

После переименования аккаунта (например, в `alizhan-bolat`) замените ссылку в `index.html` в блоке `.contacts__social` и адрес сайта в этом README.

## PDF-резюме и превью для соцсетей

- `Alizhan_Bolat_CV.pdf` (RU) и `Alizhan_Bolat_CV_EN.pdf` (EN) собраны из печатной версии страниц. После правок текста их нужно собрать заново (для английской версии откройте `en/index.html` и сохраните как `Alizhan_Bolat_CV_EN.pdf`): откройте сайт в Chrome, нажмите Ctrl+P, выберите «Сохранить как PDF», включите «Фоновая графика» и сохраните файл как `Alizhan_Bolat_CV.pdf` в корень проекта. Перед этим раскройте кейсы проектов (в Chrome они раскрываются в печатной версии сами).
- `og.png` можно заменить своей картинкой или фотографией того же размера 1200×630. После публикации Telegram может показывать старую карточку из кэша, обновить её можно через бота @WebpageBot.

## Если смените хостинг или домен

`og.png` переделывать не нужно: на картинке нет адреса сайта. Замените адрес в `<head>` обоих файлов (`index.html` и `en/index.html`): `rel="canonical"`, три ссылки `rel="alternate"` (`hreflang`), `og:url` и `og:image` (адрес картинки должен быть полным, вместе с `https://`; у английской версии это `og-en.png`). Также обновите ссылку «Сайт» в начале этого файла. Если новый адрес лежит не в корне домена (например, `site.com/portfolio/`), относительные пути `./` продолжат работать, а в `og:image` нужен полный путь.

## Публикация на Vercel

1. Загрузите проект в репозиторий GitHub (файлы в корне, `index.html` рядом с `en/`).
2. На vercel.com: **Add New → Project**, выберите репозиторий.
3. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми.
4. После деплоя русская версия открывается по адресу `/`, английская по `/en/`.

Адрес сайта в `<head>` обоих файлов (`canonical`, `alternate`, `og:url`, `og:image`) сейчас указывает на `https://portfolio-bay-theta-29.vercel.app`. Если подключите свой домен, замените его везде (поиск по проекту).
